# 五分钟搭一个选题雷达

如果你每天翻工具更新找选题，可以先让雷达做第一步：收取原文、跳过看过的链接、把命中的标题放进待审清单。打开清单，决定哪条值得做，这一步交给你。

## 打开工作台

在仓库首页点 **Code → Download ZIP**，解压，打开整个文件夹的终端。电脑里需要 Python 3.8 或以上版本。Mac、Linux 用下面的命令。Windows 如果用的是 Python Launcher，把命令开头的 `python3` 换成 `py -3`。

```sh
python3 demo/radar.py serve
```

在浏览器打开 <http://127.0.0.1:8765>。程序只监听本机回环地址。端口被占用时运行 `python3 demo/radar.py serve --port 8766`，再打开终端显示的网址。默认示范使用电脑本地的 SQLite，零 API Key，样本路径可离线运行。

| 在界面里做的事 | 你能当场检查什么 |
| --- | --- |
| 点一次「投入样本事件」 | 收到 Anthropic 原文 *Building always-on agents* 的预置标题和链接，产生 1 条待审草稿。点「查看原文」可以核对来源。 |
| 再点一次同一个按钮 | 操作记录显示「重复已跳过」，待审数量还是 1。 |
| 在终端按 Ctrl-C 停掉服务，用同一条命令重开，刷新浏览器 | 之前的草稿、编号和记录还在，因为它们已写进同一个数据库。 |
| 点「确认收录」 | 这条选题从待审核移入本机已收录清单，留下确认时间。 |
| 点「读取真实更新」 | 联网访问 LangGraph 官方仓库近期最多十条 Atom 发行记录。每条保留来源和原文地址，按标题筛选，重复链接自动跳过。 |

**样本有真实出处，投递由你触发。** 样本按钮回放固定输入，联网按钮才会获取新数据。示例用标题关键词和固定写作提纲生成草稿，没有模型调用费用。草稿可以导出继续编辑。具体功能变化需要回到版本说明查证。确认收录只写本机，不会对外发帖。

## 让它持续收更新

工作台可以保持打开。另开终端，在同一仓库运行下面的命令。程序立即检查一次，之后每 60 分钟醒来一次。按 Ctrl-C 退出。

```sh
python3 demo/radar.py watch --minutes 60
```

网络错误会在下一轮重试。电脑关机、睡眠或没有网络时无法按时拉取。恢复后再次执行命令，会检查来源当时仍然列出的最近十条记录，超过此窗口的旧更新可能漏掉。要看最新结果，刷新工作台。经常在线的电脑或服务器更适合长期运行，浏览器页面可关闭。

## 换成你每天用的项目

从 GitHub 仓库网址复制最后的 `组织名/项目名`。例如用 Python 的人可以订阅 `astral-sh/uv`，下面的命令把最近十条发行记录送入同一个工作台。这个项目的发行标题经常只有版本号，所以用 `--all`。

```sh
python3 demo/radar.py live --repo astral-sh/uv --all
python3 demo/radar.py watch --repo astral-sh/uv --all --minutes 60
```

如果你只关心 LangGraph 的 CLI 或预览版，在一个新的测试库里执行下面的命令。重复使用 `--keyword` 表示标题中命中任意一个词即可，忽略大小写；它们替代默认关键词。命令行订阅只读取该仓库的 GitHub Releases Atom，不读取代码、提交、Issue 或每条更新的正文。没有发布过 Release 的项目可能没有可用条目。

```sh
python3 demo/radar.py --db ./cli-updates.sqlite3 live --repo langchain-ai/langgraph --keyword cli --keyword preview
python3 demo/radar.py --db ./cli-updates.sqlite3 serve --port 8766
```

**同一数据库按原文网址去重。** 订阅多个仓库时可共用一个库，每条保留来源和可点击的原文。某个网址第一次进入库时会得到待审或未命中状态；下一次收到同一网址，即便改了关键词、切到 `--all` 或换成手动投递，也只记录重复，不会覆盖第一次的判断。想拿同一批内容比较两套条件时，请用不同的 `--db` 文件。工作台按钮继续读取默认 LangGraph 源，CLI 自选源写进同一个库时，刷新网页即可看到。

## 换成自己的选题

你可以手动投入一条公开文章或产品更新。替换下面命令里的三个值即可。默认关键词为 `agent`、`langgraph`、`智能体`、`工作流`、`workflow`。也可以在 `add` 命令后面添加 `--keyword 你的关键词` 或 `--all`。CLI 中传入的自定义链接仅作为来源保存，程序不会代你拉取这些自定义页面。

```sh
python3 demo/radar.py add --title "Building always-on agents" --source "Anthropic" --url "https://claude.com/resources/articles/building-always-on-agents"
python3 demo/radar.py status
python3 demo/radar.py export --state pending
```

命令行也能确认收录。下方的 `1` 换成你自己的编号。

```sh
python3 demo/radar.py approve 1
python3 demo/radar.py export --state approved > approved.json
```

导出的每条记录包含 `id`、`title`、`source`、`url`、`draft`、`state`、`received_at` 与 `approved_at`，可交给剪辑同事或后续编辑工具。时间使用 UTC。状态保存在用户主目录的 `.always-on-radar/radar.sqlite3`。需要单独做排练时，可用 `python3 demo/radar.py --db ./rehearsal.sqlite3 serve`，其它命令也指定同一文件。

## 自检

```sh
python3 demo/check.py
```

它在一次性数据库中运行独立进程，检查重复投递、并发去重、确认、筛选和导出。样本来源：[Anthropic 原文](https://claude.com/resources/articles/building-always-on-agents)。联网入口：[LangGraph 官方版本页](https://github.com/langchain-ai/langgraph/releases) · [Atom 订阅地址](https://github.com/langchain-ai/langgraph/releases.atom)。
